# TaskManagerApi
Проект для получения праткическоко опыта в разработке крупных проектов. Менеджер по задачам должен поддерживать многопользовательский опыт для решения повседневных, рабочих, коммерческих задач.

#Стек технологий
Проект будет написан на языке python с подключением базы данных postgresql и использованием следующих библиотек
  fastapi
  pydantic
  sqlalchemy
  alembic
  jwt

В проекте определены следующие сущности:

Пользователь - Участник приложения который обладает следующими данными
  Идентификационный номер
  Имя
  Логин
  Пароль (Хэш пароля)

  Функции:

-----------------------------------------------------------------------
Проект - Папка (Область) которая обладает следующими данными
  Идентификационный номер
  Название проекта 
  Номер владельца (Создателя) проекта

  Функции:

-----------------------------------------------------------------------
Задача - Функциональная ячейка проекта которая обладает следующими данными
  Идентификационный номер
  Название
  Описание
  Срок выполнения (Опционально)
  Статус выполнения
  Номер проекта к которому относится задача
  Номер тега (Опционально)
  
  Функции:

-----------------------------------------------------------------------
Тег - Категория или помиетка на задаче (Для группировки) и обладает следующими данными
  Идентификационный номер
  Название тега

  Функции:

-----------------------------------------------------------------------
Коментарий - реакция или дополнительное примечание к задаче, обладает следующими данными
  Идентификационный номер
  Содержание
  Номер пользователя
  Номер задачи в которой оставляется комментарий

  Функции:

-----------------------------------------------------------------------


Функции API:
  Получение списка пользователей - /users
  Получение пользователя по id /users/id
