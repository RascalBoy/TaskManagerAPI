# TaskManagerApi
Проект для получения праткическоко опыта в разработке крупных проектов. Менеджер по задачам должен должен поддерживать многопользовательский опыт для решения повседневных, рабочих, коммерческих задач.

#Стек технологий
Проект будет написан на языке python с подключением базы данных postgresql и использованием следующих библиотек
  fastapi
  pydantic
  sqlalchemy
  alembic
  jwt
